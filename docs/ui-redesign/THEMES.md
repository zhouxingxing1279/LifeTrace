# LifeTrace 主题 / 风格机制设计

> 状态：v1 已实现（内置"经典"与"编辑·纸质"两套风格；设置页支持导入 JSON / CSS 主题文件并启用；切换入口在页面右上角菜单）

## 目标

用户可以通过切换或导入风格文件，改变 LifeTrace 的外观（配色、字体、圆角、背景图等），并且随时能换回默认风格。界面组件结构和业务逻辑不受影响。

## 核心思路：设计令牌（CSS 变量）

所有可换肤的属性都收敛为 CSS 变量，主题 = 一组变量值。

内置的两套风格：

| 风格 | 标识 | 说明 |
| --- | --- | --- |
| 经典 | `classic` | 当前默认外观，原有样式不变 |
| 编辑·纸质 | `editorial` | 冷纸白 + 墨色 + 深绿强调，衬线标题、等宽数字 |

切换方式：`<html data-ui-style="...">` 上的属性决定生效哪一套皮肤，`editorial.css` 只在编辑风格下覆盖样式，经典风格的 CSS 原样保留。

## 风格文件格式

支持两种格式，优先推荐 JSON 令牌文件。

### JSON 令牌文件（推荐）

```json
{
  "name": "我的夜间主题",
  "version": 1,
  "tokens": {
    "--lt-paper": "#101311",
    "--lt-surface": "#171b18",
    "--lt-ink": "#e8ece7",
    "--lt-accent": "#4fae8a"
  },
  "background": {
    "image": "data:image/png;base64,...",
    "opacity": 0.18
  }
}
```

导入时按以下规则校验：

- 只允许 `tokens` 键为已知令牌白名单（`--lt-*`、`--ui-*`），忽略未知键
- 值必须是合法的 CSS 颜色、长度或字体名，禁止 `url()` 之外的任何函数与表达式
- `background.image` 只接受 `data:image/...`，不接受外部 URL 与本地路径（防追踪、防脚本）
- 文件大小上限（建议 2MB）

### CSS 覆盖文件（进阶）

```css
:root[data-ui-style="custom"] {
  --lt-paper: #101311;
  --lt-ink: #e8ece7;
}
```

用于需要更自由定制的用户。导入后存入应用数据目录，启用时通过 `<style>` 注入。CSS 文件同样有大小上限，且只允许 `:root` 变量声明块，不允许脚本、`@import` 和外部资源。

## 应用流程

```text
设置 → 风格 → 导入风格文件
  → Tauri 文件选择对话框
  → 读取并校验（JSON 或 CSS）
  → 保存到本地主题目录，出现在"我的风格"列表
  → 选择启用：写入 <html data-ui-style> + 注入令牌
  → 当前选择持久化到本地偏好，重启后保持
```

背景图作为令牌的一部分处理：`--lt-bg-image` 与 `--lt-bg-overlay` 由皮肤层统一渲染（固定定位、不遮挡操作区、尊重 `prefers-reduced-motion`）。

## 安全边界

- 主题文件不是可执行代码：不解析脚本、不加载远程资源
- 背景图仅限本地 data URL，控制文件大小
- 主题只改变视觉令牌，不改变 DOM 结构、路由和业务数据
- 导入失败时给出明确错误并回退到当前主题，不影响应用状态

当前已实现：

- 设置页新增"风格与主题"面板，可切换内置风格、导入主题文件（JSON / CSS）、启用 / 停用 / 删除自定义主题
- 自定义主题基于 `editorial` 令牌覆盖，支持 `--lt-*`、`--ui-*` 前缀令牌与 `data:image/...` 背景图
- 导入时校验令牌白名单与值安全，拒绝脚本、外部资源与超大文件
- 选择持久化在本地偏好

已知限制（后续迭代）：

- 经典风格仍有大量硬编码颜色，暂不能作为自定义主题基底；自定义主题只作用于编辑风格
- 背景图暂不支持透明度叠加和独立选择（只能随主题文件导入）
