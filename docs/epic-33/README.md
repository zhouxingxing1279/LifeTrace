# EPIC-33：英语学习闭环 2.0

> 所属阶段：LifeTrace 二期  
> 状态：规划中  
> 二期总入口：`docs/phase-2-roadmap.md`

## 目标

将现有英语模块从“每日英语阅读 + 生词本 + AI 总结反馈”升级为完整的个人英语学习系统。

核心闭环：

```text
今日学习任务
→ 阅读 / 精听 / 词汇复习 / 口语训练
→ 生词、句子、高亮、笔记沉淀
→ 间隔复习
→ 理解与输出反馈
→ 长期统计
→ 下一阶段学习任务
```

## 当前基础

EPIC-33 不是从零开发。当前桌面端已经具备：

- 每日英语文章
- 文章库
- VOA 原文音频
- 阅读状态
- 高亮
- 快捷笔记
- 划词词典
- 划句翻译
- 生词本
- 四级词汇复习反馈
- 英文总结
- AI 分析与反馈
- 学习历史和基础统计

二期优先复用并重新组织这些能力，不进行无必要的推倒重写。

## 核心建设范围

### 今日学习队列

英语首页从“今日文章”升级为“今日学习任务”。任务可包含词汇复习、句子复习、阅读、续读、精听、口语和轻量输出训练，并展示预计耗时与当日完成进度。

### 词汇复习 2.0

将当前固定阶段式复习升级为 FSRS 或等价的动态间隔重复模型，继续保留 Again / Hard / Good / Easy 交互以及来源文章、来源句子、出现次数和复习历史。

### 精听模式

在已有文章音频基础上增加面向语言学习的逐句播放器，支持逐句定位、单句循环、A-B Repeat、变速、自动暂停、字幕显示控制和快捷键，并可直接对当前句查词、收藏和记笔记。

### SavedSentence 句子库

新增正式句子学习实体，用于保存真实表达、搭配和句型。句子需要保留来源材料、原文、可选翻译、笔记、标签、音频片段位置和复习状态，并可进入间隔复习。

### 阅读闭环

继续完善当前阅读器，将用户词汇状态、单词再次遇见次数、生词、句子、高亮和笔记关联起来。阅读完成与理解/总结任务分离，已完成文章可重新打开并恢复全部学习状态。

### 理解与输出训练

将目前展示型理解问题改成真正可完成的阅读后自测，并支持轻量、标准和深度三种训练强度。完整英文 Summary 作为深度训练，不再要求每篇文章都必须完成。

### 口语训练管理

LifeTrace 不自研实时 Voice AI，重点管理训练任务与学习记录。支持 IELTS Speaking 等训练主题、训练提示词、时长、自我评分、薄弱项和笔记。实时对话可以由 ChatGPT Voice 等外部成熟能力承担。

### 学习资料库

逐步将文章库升级为统一英语学习资料库，为 Article、Audio、Podcast、Video Transcript 和用户导入文本预留统一材料模型。第一阶段仍优先使用现有稳定来源。

### 学习统计

从阅读篇数和 AI 分数扩展到长期学习时间、阅读/精听/复习/口语占比、词汇保持情况、句子积累、CEFR 难度分布、口语训练频率和长期薄弱项。

### AI 边界

英语模块不直接绑定具体模型厂商。总结分析、句子解释、语法解释和个性化建议通过统一 AI Provider / AI Gateway 调用；复习调度、播放器、字幕定位、查词、任务状态和统计等确定性能力不依赖 AI。

## 数据与架构方向

二期需要将以下长期数据作为正式领域实体，并纳入后续统一同步体系：

- EnglishLearningRecord
- EnglishMaterial / EnglishArticle
- UserVocabulary
- VocabularyReviewLog
- SavedSentence
- SentenceReviewLog
- SpeakingSession
- EnglishLearningTask
- EnglishHighlight
- EnglishNote

桌面端组件需要逐步按 dashboard、reader、listening、vocabulary、sentences、speaking、materials、statistics 和 services 等边界拆分，避免继续将全部功能堆积在大型单文件组件中。

## 验收标准

- [ ] 首页以每日学习任务作为核心入口。
- [ ] 到期词汇自动进入当天复习计划。
- [ ] 词汇使用动态间隔重复调度。
- [ ] 音频支持逐句精听和循环训练。
- [ ] 阅读或精听过程中可保存完整句子。
- [ ] 单词、句子、文章、高亮和笔记保留来源关系。
- [ ] 阅读理解问题可以实际作答并记录完成结果。
- [ ] 支持轻量、标准和深度学习流程。
- [ ] 可以记录外部 Voice 口语训练。
- [ ] 长期统计覆盖阅读、听力、复习和口语。
- [ ] 无 AI Provider 时核心学习流程仍可正常使用。
- [ ] AI 功能不绑定单一供应商。
- [ ] 新增长期学习实体具备同步能力。
- [ ] 英语前端完成必要的组件边界拆分。

## 暂不纳入

- 自研实时语音大模型
- 自研发音评分模型
- AI 自动字幕作为核心依赖
- 大规模游戏化、排行榜或积分商城
- 一次性接入所有播客与视频网站
- 多 Agent 英语老师
