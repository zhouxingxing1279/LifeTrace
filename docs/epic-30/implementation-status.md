# EPIC-30：本地加密相册实施状态

## 已实现

- Tauri/Rust 后端持有密钥，前端不接收 MEK/KEK。
- Argon2id 派生 KEK，AES-256-GCM 认证加密随机 MEK、清单、原始媒体和缩略图。
- 创建、解锁、主动锁定、空闲锁定和窗口失焦锁定。
- 本地复制导入和安全移入：密文完成并验证后才删除源文件，失败时回滚。
- 本地导出副本和安全移出，不生成远程 URL，不调用云端服务。
- 私密回收站、恢复、永久删除。
- 加密子相册名称与成员关系。
- 密文完整性检查、篡改检测、启动临时文件清理。
- 修改密码只重新包裹主密钥；必须提供旧密码。
- 忘记密码时只允许输入固定确认文本后永久删除整个私密相册。

## 本地化边界

私密相册命令仅注册在 Tauri 本地 invoke 层，不接入 Axum HTTP 服务、照片同步数据库、云同步队列、分享链接、二维码、WebSocket、WebRTC 或远程 AI。专属 CI 对私密模块执行网络与同步 API 关键字检查。
