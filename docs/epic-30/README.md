# EPIC-30：本地加密相册与私密媒体保险库

> 状态：核心能力已实现，持续加固与验收中  
> 类型：Windows 桌面端本地安全能力  
> 数据边界：**Local-only，不参与 LifeTrace Cloud、普通照片同步或远程 AI**

## 目标

在 LifeTrace 现有照片模块中提供真正的本地加密私密相册。该能力不是普通页面密码锁，而是独立的本地加密存储边界：没有正确密码时无法获得解密主密钥，忘记密码后不提供找回、恢复密钥、管理员重置或开发者后门。

## 核心原则

- 私密照片、视频、缩略图、文件名、EXIF、标签、备注和子相册信息均以密文保存。
- 用户密码通过 Argon2id 派生 KEK，随机主密钥 MEK 使用 AES-256-GCM 包装。
- Renderer 不持有 MEK/KEK，不直接读取私密文件路径。
- 私密媒体不进入普通照片同步、云端对象存储、局域网分享、二维码分享或远程 AI 流程。
- 修改密码必须提供旧密码，只重新包装主密钥，不重新加密全部媒体。
- 忘记密码后只能永久删除整个私密相册。
- 锁定状态不得暴露封面、数量、文件名、相册名或其他私密元数据。
- 应用退出、系统锁屏、休眠、窗口失焦等配置场景必须可靠锁定。

## 依赖与边界

- 依赖 EPIC-17 的安全、隐私与数据生命周期基线。
- 依赖 EPIC-18 的测试、CI/CD 与发布门禁。
- 与 EPIC-19 的日志与诊断体系联动，但私密文件名、路径、密钥和内容不得进入日志或诊断包。
- 与 EPIC-12 普通文件/照片能力保持明确隔离；**私密相册不依赖云端对象存储，也不允许被普通文件同步链路接管。**

## 验收标准

- [ ] 没有正确密码时无法解密任何私密媒体或元数据。
- [ ] 数据库、应用目录和密文文件被复制后仍无法离线还原明文。
- [ ] Renderer、普通同步服务和云端服务无法取得主密钥。
- [ ] 私密资源不会进入 Cloud、对象存储、分享和远程 AI。
- [ ] 锁定后清除会话密钥并停止私密媒体访问。
- [ ] 修改密码必须验证旧密码。
- [ ] 忘记密码不存在恢复路径，只能永久删除私密相册。
- [ ] 导入、移出、删除和异常退出均具有事务/恢复保护。
- [ ] 密文篡改能够被认证加密完整性校验发现。
- [ ] Windows 发布构建和 CI 安全测试全部通过。
