# Web 端计划 / 待办 / 备忘删除能力

本次变更保持执行中心现有信息架构和交互不变，仅补充删除能力。

## 删除规则

- 任务：删除任务本体，并原子清理关联的重复规则、重复实例、完成结果、依赖、提醒和实体关系。
- 计划：删除计划本体；计划中的任务不会被删除，而是移除 `projectId` 后保留为独立任务；同时清理直接指向计划的提醒和实体关系。
- 备忘：删除备忘本体，并清理直接指向该备忘的提醒和实体关系。
- 重复任务：保留原有“关闭重复”能力，同时提供“删除任务”；删除时执行完整任务级联清理。
- 周复盘快照：允许单独删除已保存的 `execution.weekly_review` 快照。

所有不可逆删除操作都要求用户二次确认。
